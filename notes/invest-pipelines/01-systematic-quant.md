# 系统化量化投资流水线（HRT型）

> 语境：2026-10。公开机制知识整理；HRT、Citadel Securities 等仅作**类型举例**，非任何公司内部制度披露。不确定处标注为「常见做法/公开描述」。

## 1. 这条线是谁在用

常见主体包括：

- 高频与做市型自营（公开描述中常被归为 HRT、Citadel Securities 一类）
- 以统计套利、因子/机器学习信号为主的自营量化团队
- 部分偏系统化的 CTA / 趋势跟踪与短周期执行型产品

核心问题**不是**「这个故事能不能讲圆、该不该买」，而是：**是否存在可重复、可度量、在样本外仍成立的统计优势**，以及该优势在真实摩擦（成本、延迟、冲击、容量）下是否还值得上线。

## 2. 与「投委会听故事」的差异（对照表）

| 维度 | 系统化/量化线（HRT型） | 主观投研上会线 |
|------|------------------------|----------------|
| 核心议题 | 信号是否可重复、样本外是否衰减 | 逻辑/叙事/估值/催化剂是否站得住 |
| 决策载体 | 回测报告、仿真、风险与额度评审 | 投研纪要、评级、投决会/合伙人会 |
| 人的角色 | 定研究议程、特征边界、限额与下线标准 | 判断与表达；机器多为工具而非主执行 |
| 机器角色 | 研究辅助 + 生产自动执行 | 辅助下单、风控监测为主 |
| 持仓周期 | 常见秒～日级（因策略而异，公开描述跨度大） | 常见周～年 |
| 「通过」含义 | 统计与工程门槛过关，影子盘/小资金验证 | 投决通过后建仓，纪律再约束 |

## 3. 标准步骤（流程图式）

1. **假设与研究** — 提出可检验假设（微观结构、因子、预测目标），明确数据与标签定义。
2. **特征 / 模型** — 特征工程、模型族选择、正则与复杂度控制；人定边界，机器做搜索与拟合。
3. **回测与仿真** — 强调样本外、交易成本、延迟、冲击与容量；避免只看纸面夏普。
4. **风险与产能 / 额度评审** — 限额、相关性、极端情景、可上线容量；常见做法是研究通过不等于直接全量资金。
5. **影子盘 / 小资金** — 生产路径旁路或极小规模实盘，核对仿真与真实 PnL 偏差。
6. **生产自动执行** — 人设限额与熔断；机器按规则下单、风控拦截。
7. **持续 PnL 归因与信号衰减 / 下线** — 分解来源；衰减超阈则缩仓或下线，而非「再讲一轮故事」。

## 4. 人机分工（常见公开描述）

| 环节 | 人 | 机器 |
|------|----|------|
| 研究议程与假设 | 主导 | 辅助检索与实验 |
| 特征/模型迭代 | 定边界与可解释要求 | 训练、交叉验证、网格搜索 |
| 限额、产能、下线标准 | 决策与签署 | 监控与触发告警 |
| 日常下单与路由 | 例外干预 | 主执行 |
| PnL 归因 | 解读与策略去留 | 自动归因与报表 |

原则一句话：**人定研究与限额，机器执行与复算。**

## 5. 持仓与节奏

- 公开描述中，做市与短周期统计策略常见**秒～日内**；中低频量化可到数日～数周。
- 决策节奏是「假设→实验→闸门」，不是「周会听一个标的」。
- 产能（capacity）与冲击成本往往比「观点对不对」更早成为硬约束。

## 6. 常见失败模式

1. **过拟合** — 样本内华丽、样本外坍塌；未严格隔离测试集或反复偷看测试结果。
2. **容量撞墙** — 纸面 alpha 在可交易规模下被冲击吃掉。
3. **成本低估** — 手续费、滑点、延迟、借券、交易所费未按真实路径建模。
4. **仿真与实盘鸿沟** — 未做影子盘就放量；归因把运气当成信号。
5. **下线纪律缺失** — 衰减后不断调参「救活」，实质是新的过拟合循环。


## 6.5. 规模、容量与单笔资金

公司管理规模（AUM）与「本次单笔准备动用的资金」都会改变策略水位，而且往往**不是线性放大**。AUM 变大时：冲击成本上升、成交变慢、自身交易更容易推价并伤害信号（自伤），最终撞上**容量墙**——同一套信号在小资金上成立，放到更大资金上可能只剩摩擦。

单笔/本次动用资金，常见有**双限额直觉**（定性、非公式）：

1. 占组合或策略额度的比例上限；
2. 占标的日均成交（ADV）的比例上限。

两者同时卡住，才谈得上可执行。

| 约略 AUM（直觉） | 在这条量化线上通常意味着什么 |
|------------------|------------------------------|
| 约 1000 万 | 许多中低频/部分短周期信号尚可小规模验证；容量压力相对轻，但仍要计成本与仿真偏差 |
| 约 5000 万 | 开始认真做冲击与 ADV 约束；部分窄市场或高换手策略已感水位上升 |
| 约 1 亿 | 容量与相关性评审变硬门槛；常需降换手、扩标的池或拆策略，否则纸面夏普易虚高 |
| 约 10 亿 | 多数微观结构/拥挤因子策略易撞墙；常见转向更宽池、更低换手、多策略分散，或主动缩容 |

**敏感度**：三条平行线里，系统化量化通常对规模**最敏感**——alpha 薄、换手高时，容量几乎决定策略能否活着上线。上表为行业常见直觉对照，不是公式或任何公司内部水位线。

## 7. 对个人投资者的对照

查尔斯若以**风险厌恶、债底仓**为主：

- **日常不必对标**这条线的微观交易与毫秒级执行——那是机构基础设施与专业团队的工作。
- **可对标的是配置纪律**：先写清假设与可检验标准、承认成本与容量、预设「什么情况下减仓/停用某套规则」，而不是追逐短线信号故事。
- **规模是约束不是旋钮**——钱变多不会自动让同一套规则更好用。
- 个人侧更接近「规则化再平衡 + 风险预算」，而非自建 HRT 型流水线。
