# 主观二级市场投资流水线

> 语境：2026-10。公开机制知识整理；描述买方公募、主观私募、部分 discretionary 对冲基金的**常见做法**，非某一机构内部制度。

## 1. 这条线是谁在用

- 公募基金股票投研与投资决策链条
- 主观多头 / 多空私募
- 部分 discretionary 对冲基金（研究驱动、人工判断仓位）

核心问题是：**在不确定与不完全信息下，如何形成可执行的观点，并用纪律约束建仓、加减仓与风险**——不是「有没有可重复统计优势」这一条硬闸门，而是逻辑、估值、流动性与组合约束的综合。

## 2. 标准步骤（常见流程）

1. **投研** — 行业与公司研究、财报与草根、卖方纪要；形成投资逻辑与关键假设。
2. **池子 / 评级** — 入池、评级或内部覆盖名单；合规与可投范围约束。
3. **投决或合伙人上会** — 轻重因机构而异：有的正式投委会，有的合伙人/首席拍板，有的研究员权限内可小仓试错。
4. **建仓 / 加减仓 / 止损或再平衡纪律** — 很多机构已弱化「完美退出点」，改为仓位带宽、止损线、再平衡规则。
5. **持仓跟踪与卖方互动** — 业绩跟踪、管理层沟通、卖方更新；修正假设而非死守叙事。
6. **复盘** — 归因（逻辑对/错 vs 运气）、风格与基准偏离、是否漂移。

## 3. 与量化线、一级线的边界

| 维度 | 主观二级 | 系统化量化 | 一级 PE/VC |
|------|----------|------------|------------|
| 标的 | 可交易二级证券为主 | 可程序化交易的市场 | 未上市/私有股权为主 |
| 决策重心 | 观点 + 投决纪律 | 统计优势 + 工程闸门 | 尽调 + 投委会最重 |
| 流动性 | 日度可调（受冲击与规则约束） | 极高周转或规则周转 | 年计、难退出 |
| 「上会」 | 常见但权重因机构而异 | 多为风险/额度评审，非听故事 | 投委会往往是硬门槛 |
| 周期 | 周～年常见 | 秒～日（亦有更长） | 数年 |

边界提醒：同一机构可能并行多条线；「量化增强」产品常处在主观与系统化之间，需看真实决策权在谁手里。

## 4. 考核、风格漂移与流动性

- **考核**：相对基准、绝对收益、回撤、同业排名——指标会塑造行为（追逐热门赛道、年末窗口粉饰等是行业公开讨论过的现象）。
- **风格漂移**：价值经理变成长、小盘变大盘，往往在考核压力与流动性追逐下发生；复盘应对照初始风格说明书。
- **流动性**：小盘、主题股、限售与集中持仓会放大进出成本；纪律里应显式写流动性假设。

## 5. 「退出」观念的变化（常见公开描述）

许多买方已弱化「找到完美卖点」：

- 用**目标仓位区间**替代单点目标价
- 用**假设证伪**触发减仓，而非价格到了某一整数
- 用**再平衡与风险预算**处理涨多/跌多，减少情绪化择时

这不意味着没有观点，而是把观点嵌进可执行规则。

## 6. 常见张力与失败模式

1. 研究很深，但**没有仓位与止损纪律**，盈亏由情绪决定。
2. **上会形式化**：会议确认共识，真正风险在会后集中与漂移。
3. **卖方叙事依赖过重**，独立验证不足。
4. 考核周期短于逻辑兑现周期，导致**被迫风格漂移**。
5. 忽视流动性与冲击，账面上「看得对」但组合层面输给摩擦。


## 6.5. 规模、容量与单笔资金

AUM 与「本次单笔准备动用的资金」同样约束主观二级线，只是机制更偏**流动性与风格**，而非毫秒级冲击模型。资金变大时，想保持原风格往往更难：小盘、主题、低成交标的上冲击与进出时间拉长，被迫漂向蓝筹或被迫降仓——不是线性「多一倍钱就多一倍收益」。

单笔资金的**双限额直觉**（定性）：

1. 占组合比例（集中度 / 单一发行人风险）；
2. 占标的日均成交比例（几天能建完 / 出完）。

上会通过了观点，若单笔相对 ADV 过大，执行本身就会改写价格与叙事。

| 约略 AUM（直觉） | 在主观二级线上通常意味着什么 |
|------------------|------------------------------|
| 约 1000 万 | 集中持仓与小盘仍相对可行；纪律重点在仓位上限与止损，而非机构级容量墙 |
| 约 5000 万 | 小盘进出开始吃时间；单笔 ADV 约束进入日常讨论，风格说明书更重要 |
| 约 1 亿 | 若坚持小盘/主题，冲击与漂移压力明显；常见转向更宽池或降低换手与集中度 |
| 约 10 亿 | 接近公募/大私募常见水位：可投宇宙被迫变「能买得动」的标的；容量与考核共同塑造风格 |

**敏感度**：中等，且高度依赖**小盘 vs 蓝筹**。蓝筹池对规模更宽容；小盘/主题池对规模极敏感。上表为直觉对照，非公式。

## 7. 对个人投资者的对照

查尔斯若以**债底仓、风险厌恶**为主：

- **不必对标**机构投委会的「听故事上会」仪式，也**不必对标**研究员覆盖广度。
- **可对标的是配置与加减仓纪律**：入池标准（什么能买）、仓位上限、假设证伪条件、再平衡频率——这些比寻找「完美退出点」更贴近个人可执行。
- **规模是约束不是旋钮**——资金变大不会让小盘故事更好兑现。
- 与量化线对照：个人更宜借鉴定规则的**配置纪律**，而非微观交易；与一级线对照：二级的流动性优势应用来服务再平衡，而不是频繁择时。
