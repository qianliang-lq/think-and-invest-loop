# 100 天投资知识大图

面向：查尔斯（风险厌恶 / risk averse）
主线：**债券做 base 仓** → 路径清晰后再**划拨一部分做股票卫星**
用途：工作日投资日报附「今日一点」；按 Day 1→100 顺序，一天一点，约 100 个交易日讲完。
硬约束：只讲事实与路径，不鼓动加杠杆、不鼓动「为赚钱主动吃风险」。

进度约定：从 **2026-10-26（周一）** 起 Day 1；进度记在 `progress.md`（当日完成后更新）。

## Day 1–100 知识点清单

### A. 地基（Day 1–12）

1. **风险厌恶 ≠ 零风险**：你要管的是「不可逆损失」与「被迫在低点变现」，不是波动本身。
2. **三类风险**：市场波动、信用违约、流动性（急用钱卖不出）。
3. **收益从哪来**：票息/股息、价差、再投资；债仓主靠前两项路径清晰。
4. **名义收益 vs 实际收益**：通胀会吃掉购买力；现金长期也有「静默风险」。
5. **流动性分层**：应急活钱 / 1–3 年债 / 3–7 年债 / 卫星风险资产。
6. **时间与风险匹配**：钱要用的年限越短，越不该碰长久期或股票。
7. **机会成本**：过度现金化 vs 过度追收益，两边都贵。
8. **「保证收益」话术红旗**：承诺刚性兑付、短期高息、需加杠杆才够的方案一律降权。
9. **境内账户地图**：银行理财、公募、券商 ETF、QDII 额度与开闭市差异（只作地图，不定买卖）。
10. **费用如何吃收益**：申赎费、管理费、交易佣金、冲击成本。
11. **单位净值、估值日、T+N**：看债基/货基时读懂结算节奏。
12. **阶段小结 A**：写出「应急金月数 + 闲置资金可投资年限」两行自检。

### B. 债底仓（Day 13–42）

13. **债券是什么**：借钱凭证；价格与利率大致反向。
14. **票面利率、到期收益率（YTM）**：报价里常看哪个、各自局限。
15. **利率风险**：利率升 → 存量债价跌（尤其长久期）。
16. **久期（Duration）**：利率敏感度的一把尺子；中短债为何波动更小。
17. **凸性与近似**：久期是线性近似，大波动时偏差变大（概念级即可）。
18. **信用风险**：发行人还不上；城投/产业债差异（只讲框架）。
19. **利差（Credit spread）**：比国债多拿多少补偿信用风险。
20. **国债角色**：无风险利率锚；你账本里的「03-国债」门类。
21. **政策性金融债 / 政金债**：相对国债的一点溢价与用途。
22. **短融与中短债**：1–3 年附近；你「02-中短债」的定位。
23. **纯债 vs 固收+**：纯债不碰股；「+」会混权益，风险画像变了。
24. **城投债框架**：信仰、区域分化、利差扩张时的回撤来源（事实描述）。
25. **利率债 vs 信用债组合**：底仓偏利率、增强偏信用的常见分工。
26. **债券 ETF vs 开放式债基**：流动性、折溢价、跟踪误差。
27. **样本对照**：511360 / 159649 / 511010 / 511220 / 511520 各自大致久期与信用暴露（概念级）。
28. **净值为何会跌**：利率升、利差扩、估值方法切换——不是「一定亏本金违约」。
29. **持有到期思维 vs 市值波动**：你能不能熬过净值回撤取决于动用年限。
30. **再投资风险**：利率下行时票息再投变难。
31. **收益率曲线**：短端/长端；陡峭与平坦各自常见含义（不预测）。
32. **央行与公开市场操作**：如何影响短端流动性（机制，不猜测下次动作）。
33. **通胀预期与实际利率**：对债价的传导链条。
34. **违约与展期新闻怎么读**：看主体、担保、兑付安排，不看情绪标题。
35. **杠杆债基**：为何风险厌恶者默认绕开（波动与流动性双杀）。
36. **货基/短债作缓冲**：与真正「投资底仓」的边界。
37. **债市流动性危机特征**：利差齐扩、折价、赎回潮——识别而非抄底口号。
38. **阶段小结 B**：用三句话定义你的债底仓：久期上限、信用暴露上限、不可用杠杆。

### C. 组合骨架（Day 43–58）

39. **目标配比不是预测**：先定风险预算，再填产品。
40. **核心-卫星**：债=核心；股/黄金=卫星且有上限。
41. **应急金先锁**：3–12 个月支出放活钱，不进长债/股。
42. **再平衡**：偏离带宽（如 ±5%）触发调回——纪律代替感觉。
43. **买入节奏**：一次性 vs 分批；风险厌恶者常用分批降低时机风险。
44. **卖出纪律**：先问「流动性需求变了吗」，再问「估值/利差」。
45. **人民币资产为主的约束**：在岸渠道、额度、换汇摩擦。
46. **汇率风险入门**：若将来碰美元债/QDII，收益=资产+汇率。
47. **黄金在组合里的角色**：避险叙事 vs 实际相关与波动；你账本「01-黄金」定位为小卫星。
48. **相关不等于对冲**：股债同跌年份要心里有数。
49. **税费与账户摩擦**：利息税、股息税、交易税对净收益的影响（境内常识级）。
50. **家庭资产负债表视角**：房贷、稳定收入决定风险预算，不只看「有一百万现金」。
51. **目标收益率陷阱**：先定最大可回撤，倒推配比。
52. **压力测试三问**：利率+100bp、股-30%、要用钱时——组合会怎样。
53. **文档化**：目标配比、再平衡规则、禁止清单写进账本 README。
54. **阶段小结 C**：产出一页「目标配比草图」（可暂定数字，标成待你确认）。

### D. 股票卫星（Day 59–82）

55. **为何股放后面**：先有债底仓与应急金，股票回撤才不逼你割肉。
56. **股票收益来源**：盈利增长、估值变化、股息；路径比债更吵。
57. **波动与回撤**：-20%/-40% 历史量级要能睡得着才配得上比例。
58. **风险预算切一刀**：例如总资产 0–20% 作权益上限（数字由你定，课只讲方法）。
59. **高股息逻辑**：分红稳定性、盈利质量、估值；对接「05-高股息」。
60. **红利 ETF（如 510880）**：分散个股暴雷，仍有风格与行业暴露。
61. **招行 / 长电样本怎么读**：银行息差与资产质量；水电来水与电价（框架）。
62. **估值常识**：PE/PB/股息率；高股息不等于永远便宜。
63. **盈利与分红的可持续**：一次性分红、周期性高峰的陷阱。
64. **指数基金 vs 主动基金 vs 个股**：成本、行为、可控性权衡。
65. **宽基指数角色**：若扩大权益，先理解 β，再谈主题。
66. **行业与主题风险**：集中押注与你的风险厌恶冲突点。
67. **回撤中的行为**：越跌越买要有预算与规则，否则是摊平幻觉。
68. **止损 vs 再平衡**：风险厌恶组合更常用再平衡，少用情绪止损。
69. **财报季噪音**：区分经营事实与叙事；卫星仓不追热搜。
70. **A/H/美股差异**：交易机制、假期、汇率（概念地图）。
71. **定投在权益卫星的用法**：降低择时压力；与债底仓「买完持有」可并存。
72. **何时不加股票**：应急金不足、动用年限短、心理回撤预算为 0。
73. **股债切换幻觉**：用再平衡代替「我能抄底」。
74. **阶段小结 D**：写下「权益上限 % + 高股息/宽基/个股占比上限 + 禁止清单」。

### E. 护栏与复盘（Day 83–100）

75. **损失厌恶**：亏的疼大于赚的爽——规则要写在冷静时。
76. **确认偏误**：只搜支持自己仓位的消息。
77. **近因偏差**：刚涨完觉得债「没用」、刚跌完觉得股「永别」。
78. **处置效应**：爱卖赢的、死扛亏的。
79. **杠杆与衍生品**：对风险厌恶者默认关闭的原因。
80. **朋友圈收益率**：不可比、含水、生存者偏差。
81. **「这次不一样」清单**：利率体制、监管、流动性——要证据不要口号。
82. **年度检查单**：配比、久期、信用下沉、权益是否越界、应急金。
83. **季度轻检**：只看规则触发，不看故事。
84. **记录模板**：买入原因、持有前提、失效条件——写下来才算数。
85. **信息饮食**：日报看状态；大图看结构；少刷盘。
86. **卖方研报怎么用**：事实与假设分开；结论当意见不当指令。
87. **买方经理差异**：公募约束、考核、风格漂移——对照已有 TOP10 材料。
88. **常见坑合集**：刚兑幻想、长久期赌降息、信用下沉博收益、主题炒作当底仓。
89. **家庭沟通**：大额配比变更先对齐年限与睡眠标准。
90. **健康与工作风险**：人力资本中断时组合要更能变现。
91. **账户便利与简化**：受益人、备份、减少产品数量。
92. **百年尺 vs 百日课**：100 天只是入门地图，之后按年复用检查单。
93. **把大图收成一页**：五阶段 + 你的数字（配比/上限）。
94. **模拟演练**：假想利率急升 + 股灾同月，走一遍再平衡。
95. **知识反刍**：重读 Day 12/38/54/74 四次小结，改数字。
96. **开放问题清单**：收入稳定性、房贷、美元比例——答完再细化配比。
97. **与五门类日报的关系**：日报=天气；大图=航海图；不混用。
98. **毕业标准**：能不靠助手口头解释「我的债底仓怕什么、股票卫星为何后上」。
99. **维护模式**：大图讲完后，日报「今日一点」改为复习卡轮换或你指定新主题。
100. **总收束**：风险厌恶者的一句话策略——**先睡得着，再谈多一点收益；债做底，股做有上限的卫星。**

## 日报「今日一点」写法（给例程）

- 标题：`今日一点 · Day N/100 · 《短标题》`
- 正文：约 150–250 字，口语可扫；先一句结论，再 2–3 句机制/例子，末句「和你底仓的关系」。
- 禁止：荐股、目标价、加仓煽动、杠杆建议。
- 进度：写完后把 `progress.md` 里的 `next_day` +1，并注明日期。
