# 投资账本

这是一个系统化的投资研究与记录仓库，用于跟踪和分析不同资产类别的投资机会。

## 投资门类

本账本涵盖五大投资类别：

- [01-黄金](./01-黄金/) - 黄金类资产
- [02-中短债](./02-中短债/) - 中短期债券
- [03-国债](./03-国债/) - 国债类资产
- [04-纯债](./04-纯债/) - 纯债基金
- [05-高股息](./05-高股息/) - 高股息分红股票

## 使用说明

每个投资门类包含以下结构：

- `notes/` - 存放研究笔记、分析文档
- `data/` - 存放数据快照、历史记录

您可以在各个类别目录下的 README.md 中查看该类别的详细说明。
